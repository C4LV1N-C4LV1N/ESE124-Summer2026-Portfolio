## Featured Projects

### 1. Snack Register

This program calculates the total cost of chips, juice, and cookies based on the quantities entered by the user. It calculates the total price in cents and then displays the final cost in dollars with two decimal places.

- **Skills demonstrated:** Variables, user input with scanf, arithmetic calculations, integer and floating-point data types, and formatted output with printf.
- **Source and details:** snack_register.c

### 2. Receipt Writer

The Receipt Writer program reads quantities of coffee, sandwiches, and cookies, calculates the subtotal, tax, discount, and final total, and saves the results to a receipt.txt file. It represents my growth as a programmer because I moved from only knowing basic calculations to using multiple functions, conditional logic, file I/O, and modular program design.

- **Skills demonstrated:** Functions, modular design, file I/O, formatted output, conditional statements, user input, and arithmetic calculations.
- **Source and details:** receipt_writer.c

### 3. BroBank

BroBank is a modular C banking application that processes deposits, withdrawals, and account transfers using multiple data structures. Its strongest features include a transaction queue, an undo stack for reversing successful transactions, and graph traversal using BFS and DFS to analyze account transfer relationships.

- **Skills demonstrated:** Abstract data types, structures, circular queues, stacks, graph traversal, BFS, DFS, modular C programming, transaction validation, and testing.
- **Source and details:** brobank.c

## What I Learned

Through these projects, I developed my understanding of C programming starting from basic input, variables, and calculations to more advanced modular programs and data structures.
