# Reflection

## What Improved

My C programming skills improved from writing simple programs with variables, input, and calculations to designing larger programs using functions and abstract data types. I became more comfortable working with queues, stacks, structures, arrays, and file operations. BroBank especially helped me understand how multiple data structures can work together to solve a larger problem.

## What Remains Difficult

Pointers, dynamic memory allocation, and managing more complicated data structures are still areas that I want to improve on. Debugging programs that involve several structures at the same time can also be challenging because an error in one part of the program can affect another part.

## Challenge I Overcame

One challenge was implementing BroBank so that transactions were validated, processed in the correct order, and stored for undo operations. I also had to understand how BFS and DFS use different data structures to search the account-transfer graph.

## Next Learning Goal

My next learning goal is to become more confident with dynamic memory allocation, linked lists, and more advanced pointer-based data structures. I also want to implement C coding in embedded systems design to incorporate hardware into my projects as well.
